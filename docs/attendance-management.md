# ระบบสถานที่และการลงเวลา

เข้าแอดมินที่ /admin-login หรือ /admin (บัญชีผู้ดูแลที่ผูกเครื่องเดิม)

1. /admin/workforce: สร้างสถานที่ ใส่พิกัดและรัศมี 0–1000 กม. แล้วเลือกผู้ใช้ที่มีสิทธิ์เห็นและลงเวลาในสถานที่นั้น ทุกคนรวมถึงแอดมินต้องได้รับสิทธิ์สถานที่ก่อนลงเวลา
2. ตั้งค่าให้ต้องมีรูป หรือแนบรูปเป็นตัวเลือก ใช้กับเข้า เช็คอินระหว่างทาง และออก
3. /admin/users: จัดการสถานะ แผนก ฝ่าย สาขา กลุ่ม และโควต้าลาพักร้อนต่อคน
4. ตั้งตารางรายสัปดาห์สำหรับสาขาและกลุ่ม ตารางเฉพาะสาขา+กลุ่มมีลำดับสูงสุด แล้วสาขา แล้วกลุ่ม แล้วค่าเริ่มต้น วันหยุดบริษัทเป็นวันหยุด รายงานจะแสดงผลตาราง ไม่ปิดกั้นลงเวลาวันหยุด
5. /check-in: เลือกสถานที่ เปิด GPS ลงเวลาเข้า เช็คอินระหว่างทางหลายครั้ง และออก ประวัติรายวันใช้วันไทย (Asia/Bangkok) เวลาบันทึกมาจากฐานข้อมูล
6. /admin/attendance: สรุปตามช่วงวันและดาวน์โหลด Excel 2 ชีต (สรุป/รายการเช็คอิน) สถานะออนไลน์อัปเดตเมื่อใช้งานแอปทุกนาทีและถือว่าออนไลน์ภายใน 2 นาที รีเฟรชรายงาน 30 วินาที
7. /admin/usage: จำนวนแถวจริงในระบบและลิงก์หน้า Usage ของผู้ให้บริการ ยังไม่มีสิทธิ์ Management/Billing API จึงไม่มีตัวเลขโควต้าหรือค่าใช้จ่ายของผู้ให้บริการภายในแอป
